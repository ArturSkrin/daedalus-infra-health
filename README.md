# daedalus-infra-health

Infra Health Tracker для хакатону «Self-Aware Infrastructure». Фітнес-трекер для інфраструктури: не дашборд, з якого інженер вичитує причину, а екран, який показує рішення, вже ухвалене агентом Triage, і підстави йому вірити.

## Мета

Інженер відкриває трекер вранці і після релізу. За кілька секунд він має побачити одне з трьох:

| Слово на екрані | Рішення |
| --- | --- |
| **СПОКІЙНО** | нічого не робити |
| **ЗАПЛАНУВАТИ** | створити тікет у спринт |
| **ЗАРАЗ** | втрутитись сьогодні |

Плюс службовий стан **НАОСЛІП**: даним не можна вірити, спочатку полагодити збір.

На головному екрані пʼять показників, і жоден із них не є сирою метрикою:

1. **Стан флоту одним словом**: згортка чотирьох інших за правилами пріоритету.
2. **Користувачі зараз**: чи страждають люди прямо зараз (RED як стан).
3. **Що назріває**: єдиний показник із майбутнього (передвісники агента плюс тиск ресурсів).
4. **Чи можна вірити**: чи є потік даних і чи повний він.
5. **Як пройшла доба**: цінність у спокійний день, а також тиха регресія після релізу.

## Як переглянути прототип

Прототип у роботі. Після появи він читатиме `mock_data/<id>.json` і перемикатиме зріз через параметр URL:

```
/?scenario=s07_outage
```

Список зрізів для перемикача лежить у [mock_data/index.json](mock_data/index.json).

## Як відтворити сценарії

Без прототипу правила можна прогнати еталонною реалізацією на Python 3:

```bash
python mock_data/evaluate.py
```

Вивід показує стан кожного показника і рішення для всіх десяти зрізів і звіряє з очікуваним:

```
scenario                  users       forecast    trust       day           verdict       ok
s01_calm                  Добре       Чисто       Повна       Спокійна      СПОКІЙНО      ✓
s03_release_regressed     Добре       Чисто       Повна       Погіршилась   ЗАПЛАНУВАТИ   ✓
s05_agent_disconnected    —           —           Наосліп     —             НАОСЛІП       ✓
s07_outage                Зламано     Чисто       Повна       Спокійна      ЗАРАЗ         ✓
...
10/10 scenarios match metrics_spec.md
```

Один зріз із проміжними числами:

```bash
python mock_data/evaluate.py s03
```

Перегенерувати мок-дані після зміни фікстури або порогів:

```bash
python mock_data/generate.py
```

## Чекліст відповідності вимогам

| Вимога | Стан | Де |
| --- | --- | --- |
| Не більше 5 показників на головному екрані | так, рівно 5; черга інцидентів є списком, не показником | metrics_spec.md |
| Для кожного показника: яке рішення змінює, поріг, поля API | так | metrics_spec.md |
| Хоча б один показник із горизонтом у майбутнє | так, показник 3 через `precursorMatches` і PSI | metrics_spec.md, розділ 3 |
| Видно, коли даним не можна довіряти | так, показник 4 плюс індикатор довіри в кожному з 2, 3, 5 | metrics_spec.md, розділ 4 |
